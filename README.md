# Ecommerce-sales-analysis-excel
🛒 Ecommerce Sales Analysis Dashboard 📊 (Microsoft Excel)
A dynamic, interactive data visualization tool built to explore Ecommerce data-focusing on overall sales performance, product performance, state-wise comparisons and order distribution by channel.


## 📌 Project Overview
This project presents an interactive **E-commerce Sales Analysis Dashboard** built entirely in **Microsoft Excel**. The dashboard helps analyze sales performance, product categories, product performance, monthly trends, payment mode-wise order distribution using Pivot Tables, Pivot Charts, Slicers, and Excel formulas.

The goal of this project is to transform raw sales data into meaningful business insights that support data-driven decision-making.


## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Text to Columns
- Excel Formulas (SUMIFS, COUNTIF, IF, IFS, INDEX-MATCH/XLOOKUP, etc.)


## 📂 Dataset

The dataset contains raw e-commerce order transactions captured throughout 2024 (January 1, 2024 – December 31, 2024) across India.
Total Records: 1,112 rows
Total Columns: 12 attributes
Unique Orders: 1,100 


## 📈 Dashboard Features

- 📅 Monthly Sales Trend
- 🌍 State-wise Sales Analysis
- 🛍️ Category Performance
- 🛍️ Product Performance
- 💰 Payment Mode-Wise Order Distribution
- ⭐ Top 10 Best Selling Products
- 🎛 Interactive Filters (Slicers)


## 📊 Key Insights

- **Fashion** is the highest revenue-generating category, contributing **3.2 million** in total sales.	
- The overall Order Return Rate is **32.45%**, indicating that nearly one-third of all orders were returned or canceled.
- **Jeans** emerged as the **top-performing product**, achieving the highest sales score.
- The **Books** category recorded the highest returned/canceled sales value at 1 million, followed by **Beauty**,											   with **Karnataka** leading returns/cancellations in **Books** and **Maharashtra** leading in **Beauty**.	
- The **Mobile App** is the primary sales channel, accounting for **75%** of all orders and generating **10.1 million** in sales.
- **Maharashtra** is the **highest** revenue-generating state, contributing **2.05** million in sales, followed by **West Bengal** with **1.80 million**.
- **23%** of total returned orders (42 out of 180) were **COD** orders, indicating higher return risk. 															Offering discounts on prepaid orders could encourage prepaid purchases and help reduce return rates.
